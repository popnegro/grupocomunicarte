# QA FASE 08 — Responsive integral + navegación\n\n## Alcance\n\n- Desktop y Mobile.\n- Explorador → Detalle → Volver.\n- Ubicaciones Destacadas → Detalle / mapa.\n- Cart persistente entre vistas.\n- Media Kit vacío / con soportes.\n- Solicitud comercial.\n- Rutas públicas directas.\n\n## Correcciones aplicadas\n\n1. Se agregaron rutas explícitas para `/ubicaciones/*`, `/mediakit/*`, `/servicios/*` y `/blog/*` para evitar que el fallback global redirija estas rutas a `/`.\n2. Se agregaron protecciones responsive contra overflow horizontal en `html`, `body` y `#root`.\n3. Se deshabilitó el zoom accidental de formularios en iOS/Android mediante tamaño de fuente de 16px en Mobile.\n4. Se añadió `touch-action: manipulation` a controles interactivos.\n5. Se añadió `:focus-visible` para navegación por teclado y accesibilidad.\n\n## Flujo esperado\n\n```text\nLanding\n  ↓\nExplorador / Ubicaciones\n  ↓\nDetalle\n  ↓\nAgregar al Media Kit\n  ↓\nCart único\n  ↓\n/mediakit\n  ↓\nSolicitud\n```\n\n## Nota de validación\n\nEl build debe ejecutarse en un entorno con las dependencias instalables. El ZIP de trabajo no incluye `node_modules`; el entorno anterior no pudo resolver `zustand@5.0.14` desde su registry.\n
